# Roovia onboarding-image set

## Goal

Create three original portrait PNG backgrounds for Roovia's first-run carousel. They should borrow the visual *approach* of `OnboardingDesign5`—a saturated monochrome field, polished 3D objects, and a strong upper-screen focal point—without reproducing its screen UI, copy, or travel-service imagery.

## Deliverables

Save three full-screen, text-free PNGs in the repository root:

- `onboarding-plan.png`
- `onboarding-drive.png`
- `onboarding-share.png`

They are project assets rather than complete screen mockups: no status bar, navigation controls, logo, text, or watermark. The lower 45% remains quiet for mobile overlay copy and actions.

## Visual sequence

1. **Plan** — a refined Roovia version of the supplied suitcase reference: a field map, compass, route card, and small camper-travel cues. Palette: trail-blaze orange with warm map-paper highlights.
2. **Drive** — a compact modern camper van travelling along a map-like winding road, presented as a playful 3D diorama. Palette: lake blue with spruce and cream accents.
3. **Share** — a campsite memory scene with a van, lantern, photo prints, and a shared route journal. Palette: moss green with contour-brown and paper-cream accents.

## Constraints and validation

- Portrait composition matching the mobile onboarding context.
- Original scenes; no copied marks, copy, or UI from the Design 5 references.
- The existing `onboarding-photo-suitcase.png` is a visual/compositional reference only; the Plan image is regenerated as an original Roovia-specific scene.
- Inspect every output for legible, uncluttered composition, text-free pixels, and clear copy space.
- Copy all three selected generated PNGs to the repository root and verify their dimensions, existence, and non-zero size.
